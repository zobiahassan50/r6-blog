# Media

- `r6-hero-poster.webp` / `.jpg` / `.png` — homepage hero poster.
- `card-*.jpg` — 16:9 article cards used on the home grid, guides hub, and related UI.
- `placeholder-*.jpg` — page-level artwork (home, guides, community, FAQ, contact, product).
- `blog-uploads/` — source article artwork:
  - `{slug}.jpg` — normalized upload used by `scripts/generate-seo-assets.mjs`
  - `{slug}.source.jpeg` — original full-resolution source (optional)
  - `product.source.jpeg` — source for product / OG artwork
